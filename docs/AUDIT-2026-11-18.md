# Audit — Agentic Arbitrage Factory (2026-11-18)

Scope: static read of `factory.py`, `config/`, `core/`, all four agents, CI/Docker, handoff + plan docs. Ran the test suite and three small repros. Nothing was deployed or sent to external services. Reddit mirrors, Cloudflare/wrangler, `npm build` of generated sites were **not** exercised.

Labels: **confirmed** = reproduced or read in code; **assumed** = inferred; **unverified** = not checked.

## Verified baseline
- `uv sync --extra dev --extra dashboard` then `uv run pytest -q` → **72 passed** (confirmed). A fresh clone without sync fails collection (`aiohttp` missing) — environment only.
- Tests cover mode guardrails and "don't fake it" behaviour. They do not cover whether generated sites build, rank, or earn.

## P0 — thesis is stale
1. **The product's headline hook has expired.** Site copy, plan, and handoff are built on "Level 2 charger credit before **June 30, 2026**" (`constructor.py:434,477,568`; handoff). Today is 2026-11-18. Deploying this copy would publish a false/out-of-date claim on a money/tax topic. *Confirmed* that the copy says this; *unverified* by me what current federal/state law is — check before rewriting. Residual value is state/utility rebates only, which changes demand, competition, and monetization assumptions the validation snapshot was built on.

## P1 — evidence the system treats as real is not
2. **Keyword "evidence" is a test fixture with no provenance.** `ValidationConfig.keyword_snapshot_path` defaults to `tests/fixtures/ev_charger_keyword_snapshot.csv` (5 rows, source "manual", captured 2026-04-01). Staging and production validation read it as real SERP data. Numbers are 7+ months old and pre-date the credit expiry. (confirmed)
3. **Staging silently injects fake pain points** (`red_queen.py:120` — mock fallback is `not is_production`, not `is_demo`). Staging discovery evidence can be fabricated while the docstring and handoff imply real-only. (confirmed)
4. **Validation score double-counts one input.** `data_score` and `automation_score` are both `fragmentation.automation_potential` (`midwife.py:613-616`) → 45% of the score is one number, which starts at 5.0 and rises with any reachable URL. A 200 response from a URL gives most of the pass. (confirmed)
5. **Monetization is a hard-coded table + constants.** Affiliate commissions ("ChargePoint $50-100/sale", "EVgo $25/signup") are not sourced; revenue = volume × 5% × fixed rates. No program membership or payout is checked. Treat the MRR figure as an illustration, not an estimate. (confirmed; commission values unverified)
6. **Competition gap is assumed, not measured.** No SERP check. For EV incentives, likely incumbents include government/DOE and utility pages, incentive databases, and installer/lead-gen sites — *unverified*, but "low competition" is not supported by any code path.

## P1 — generated-site defects (Constructor)
7. **`robots.txt` is malformed**: written with literal `\n` (`'User-agent: *\\nAllow: /...'`) so the file is one line. `Sitemap:` is also a relative URL. (confirmed by repro)
8. **Sitemap base is hard-coded `https://example.com`** (`constructor.py:388,615`) → sitemap submits wrong URLs. (confirmed)
9. **Two near-duplicate generators** (`TemplateGenerator`, `EVChargerTemplateGenerator`); `TemplateGenerator._sitemap` takes args the other class's call site doesn't. Drift risk. (confirmed)
10. `page_count = len(templates) * 50` is invented, then stored and shown as pages generated. (confirmed)
11. Cloudflare adapter guesses the URL (`<niche>.pages.dev`) instead of parsing wrangler output; `deploy` script in package.json is `wrangler deploy` (Workers) while the adapter uses `pages deploy dist`. Whether the EV template emits `output: 'export'` + `distDir: 'dist'` was **unverified**. Stray literal `"\\n"` in `print` calls. Demo health check always returns True.
12. No affiliate/lead-gen disclosure, privacy, or "not tax advice" copy in templates (grep found none). Needed for a tax/incentive site. (confirmed absence in grep)

## P1 — Mortician
13. **Rule 2 culls productive sites**: a site at 300 organic users/day, $0 revenue, day 70 → `should_cull=True` (repro). Rule 4's traffic exemption only applies under 60 days. Also returns `recommendation="KEEP"` while `should_cull=True`. Revenue is manual-import, so early culls on "no revenue" are likely. (confirmed)
14. **Metrics provenance mislabelled**: `collect_all_metrics` hard-codes `provider: "demo"` in evidence and re-saves the latest stored metric each run into an AUTOINCREMENT table → duplicate rows that skew 7-day averages and decline detection. (confirmed from code/schema; duplicate effect assumed)
15. `hash(site.id)` in mock metrics is randomized per process → demo not reproducible. Minor.

## P2 — infra / ops
16. **CI is broken**: matrix includes Python 3.8–3.10 but project requires ≥3.11; installs `requirements.txt` / `requirements-dev.txt` which don't exist; `uv` not used. (confirmed)
17. `web_dashboard.py` binds `0.0.0.0` with `reload=True`, no auth. Fine locally; do not expose. (confirmed)
18. Discovery depends on third-party Pushshift mirrors (arctic-shift, pullpush) — reliability, coverage, and Reddit-data terms are *unverified*. `search_subreddits` still hits www.reddit.com, which the code's own comment says 403s. Pain detection = regex + crude word-list sentiment.
19. Docs drift: AGENTS.md/README/BuildConfig say Hono + D1 + Drizzle; code generates Next.js. "5-minute build" is unmeasured. Default `FACTORY_MODE` is `demo`, so `python factory.py run` out of the box produces fabricated successes (labelled, but easy to misread).
20. `factory.get_status().ready_to_fund` is true if a keyword snapshot path is configured (non-empty string) — which it always is by default (finding 2). (confirmed in code; interacts with #2)

## Strategic advice
- **Don't spend on production mode with the 30C thesis.** Re-ground the vertical first.
- **Wrong frame:** a factory that scales page count is the opposite of what the data supports. Everything here is validated by proxies (URL reachable, regex hits). One hand-verified site with real data beats 50 generated ones, and mass-templated thin pages carry search-quality risk (*assumed*, not tested here).
- **Smallest credible validation (1–2 weeks, ~$0):** (a) pull real Search Console/keyword data for state/utility rebate queries as of now; (b) manually list the top 10 SERP results for 10 queries — who ranks, how thin; (c) ask 3–5 EV installers whether they'd pay per qualified lead and how much. Buyer is the installer, not the visitor; ad/affiliate revenue is the weak stream.
- **Stop conditions:** no query set with ≥ a few hundred combined monthly searches that a small site can plausibly rank for; or SERP dominated by government/utility pages with no gap you can fill with better data; or no installer will commit to a price per lead.
- **If you proceed, fix in this order:** (1) update/remove all 30C-deadline copy and add disclaimers; (2) replace fixture snapshot with real dated data and fail validation if absent outside demo; (3) mock fallback → demo only; (4) fix score double-count and make gate depend on a SERP check; (5) robots/sitemap/base-URL bugs and verify `npm run build` on the generated EV site; (6) Mortician rule 2 + provider label + de-dupe metrics; (7) repair CI to use `uv` + Python 3.11/3.12.
